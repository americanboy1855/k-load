# K LOAD V1.0 для Windows — чек-лист приёмки

Установщик: **K-LOAD-V1.0-Setup.exe** (артефакт CI или Release).
Система: Windows 10/11 x64. Права администратора не нужны.

## Установка и первый запуск

- [ ] Запустить Setup.exe → SmartScreen: «Подробнее» → «Выполнить в любом случае»
- [ ] Установщик на русском, без запроса пароля (per-user)
- [ ] Ярлык появился в меню «Пуск»
- [ ] Запуск из «Пуска» → окно 560×670 без заголовка, пиксельный телевизор
- [ ] Кнопки окна: свернуть работает, закрыть работает
- [ ] Ресайз за края окна: меньше/больше в пределах 0.8×–1.4×
- [ ] Перетаскивание окна за верхнюю полосу работает

## Скачивание (по каждой платформе)

- [ ] **YouTube** — вставить ссылку на видео → СКАЧАТЬ → файл в «Загрузки/K LOAD»
- [ ] **YouTube** — МУЗЫКА (mp3) → аудиофайл
- [ ] **TikTok** — видео без вотермарки
- [ ] **Instagram** — рилс (публичный аккаунт)
- [ ] **VK** — видео/клип
- [ ] **Pinterest** — фото (jpg) и видео
- [ ] **Spotify** — трек по ссылке (найдёт на YouTube)
- [ ] **Apple Music / SoundCloud** — трек
- [ ] **ХРОН** — вырезка «ОТ–ДО» → имя файла содержит [00:00–00:10]
- [ ] **Плейлист** — целиком → папка «Плейлист/01 - …»
- [ ] **Пачка** — 2–3 ссылки разом → обе строки отработали
- [ ] **Поиск по названию** — трек найден и скачан

## Поведение

- [ ] Пауза на середине → докачка с места остановки
- [ ] Смена папки (кнопка-папка) → файлы пошли в новую папку
- [ ] Перетаскивание готового файла мышью из строки в Проводник
- [ ] Отключить сеть (Wi-Fi выкл) → плашка о сети; включить → задание продолжилось
- [ ] Русские названия файлов: кириллица в именах не ломается

## Переустановка и удаление

- [ ] Установить Setup.exe ПОВЕРХ старой версии → файлы обновились, ярлыки целы
- [ ] Деинсталляция из «Приложений» → папка и ярлыки убраны, загрузки не тронуты
