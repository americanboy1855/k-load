# K LOAD

Загрузчик музыки и видео для macOS. Вставь ссылку — получи файл.

- **Источники:** YouTube · TikTok · Instagram · VK · Spotify · Apple Music · SoundCloud · Pinterest
- **Режимы:** ВИДЕО · МУЗЫКА (MP3, FLAC…) · ХРОН — вырезка фрагмента по таймкодам
- **Диспетчер загрузок:** прогресс, очередь, перетаскивание готовых файлов в любые программы
- **Папка на выбор**, красивый ретро-телевизор и янтарный фосфор
- Универсальный бинарь: Apple Silicon + Intel. Все инструменты в комплекте — работает сразу после установки

## Установка

1. Скачай **K-LOAD-V1.0.pkg** из [Releases](../../releases/latest) — рядом лежит **K-LOAD-Instrukciya.pdf**.
2. Открой его — macOS предупредит, что сборка не проверена Apple. Нажми **Готово** — это нормально.
3. Открой **Системные настройки → Конфиденциальность и безопасность** → внизу нажми **«Открыть в любом случае»** → введи пароль.
4. Готово: вставь ссылку — и жми **СКАЧАТЬ**.

Файлы сохраняются в «Загрузки/K LOAD». Папку можно изменить кнопкой-папкой внизу слева.

### Windows 10/11 (x64)

1. Скачай **K-LOAD-V1.0-Setup.exe** из [Releases](../../releases) — рядом **K-LOAD-Instrukciya.pdf**.
2. Установка на русском, без прав администратора. SmartScreen: «Подробнее» → «Выполнить в любом случае» (сборка не подписана).
3. Установка новой версии поверх обновляет приложение автоматически.

Файлы сохраняются в «Загрузки\K LOAD». Папку можно изменить кнопкой-папкой в левом нижнем углу.

## Использование

1. Вставь ссылку или введи название трека — подожди разбор.
2. Выбери режим: **ВИДЕО**, **МУЗЫКА** или **ХРОН** (фрагмент по таймкодам «ОТ–ДО»).
3. **СКАЧАТЬ** — прогресс в диспетчере; готовые файлы можно перетащить мышью в любую программу.

## Важно

Используйте K LOAD только для контента, на который у вас есть права: собственные записи, открытые лицензии или разрешение правообладателя. Загрузка материалов с DRM невозможна.

## Внутри

Flutter (интерфейс) + C++-ядро через FFI + yt-dlp и ffmpeg в комплекте (лицензии — в пакете, папка tools/LICENSES).
