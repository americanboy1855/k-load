HOW TO USE

Paste a link or type a track name — the app will find the recording.

Pick a mode:
• VIDEO — full clip, up to 4K
• MUSIC — track as MP3, FLAC and more
• CHRON — cut a fragment by timecodes FROM–TO

You can download whole playlists, batches of links and search
tracks by name — built-in search will find the recording.

Progress is shown in the download manager at the bottom: queue,
pause, drag finished files into any app.

Files are saved to Downloads/K LOAD.
Change the folder with the folder button in the bottom-left corner.
