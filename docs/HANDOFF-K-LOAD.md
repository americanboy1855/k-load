## Что уже сделано (этап 1 + каркас этапа 2)

- **kdcore/** — ядро скачивания на чистом C++17 (порт core/engine с JUCE 1:1):
  - очередь по одному заданию, вызовы yt-dlp со всеми флагами, парсер прогресса
    («Качаю 2 из 14», «Склеиваю…», проценты), пачки ссылок, плейлисты целиком,
    cookies-from-browser (невидимая цепочка браузеров), поиск по названию
    (YouTube-страница + запасной ytsearch/scsearch), закрытые каталоги
    (Spotify embed, iTunes lookup, og:-разметка), Pinterest-фото через oEmbed,
    VPN-монитор (route -n get default), журнал движка.
  - C-API `kdcore/include/kd_capi.h`: kd_engine_create/destroy, kd_set_event_port
    (события queue_changed/probe/vpn на Dart-порт через Dart_PostCObject),
    kd_snapshot, kd_split_links, kd_enqueue_batch/photo, kd_cancel/remove,
    kd_clear_finished, kd_probe_blocking/async, kd_vpn_state, kd_default_dest,
    kd_tools_status.
  - universal dylib arm64+x86_64; 52 контрактных теста зелёные
    (`kdcore/build/kd_tests --live` бьют по живым источникам).
- **app/** — Flutter macOS (проект kload, org ru.kvartal):
  - `lib/kd/kd_bindings.dart` — FFI-мост ко всему C-API, события в Stream;
  - `lib/main.dart` — технический каркас (заглушка под замену): поле ввода,
    enqueue, список очереди с прогрессом, cancel/remove;
  - песочница App Sandbox выключена (нужны сеть, файлы, cookies);
  - `scripts/dev-build.sh` — сборка с учётом iCloud-Desktop (см. PLAN.md).
  - Контрольный запуск: «KD_BOOT: ядро 1.0.0 · инструменты: найдены».

## Блоки интерфейса (очерёдность сборки — согласовать с заказчиком)
1. Каркас окна и навигация/меню (структура).
2. Поле ввода: ссылки/название; кнопка с живым счётчиком ссылок; чипы
   Видео/Музыка · качество · аудиоформат.
3. Карточка разбора (probe): превью, бейдж сервиса, название/канал, длительность,
   доступные высоты, «плейлист целиком», выбор видео/музыка.
4. Плашка очереди: превью, бейдж, живой статус/прогресс, ошибки по-человечески,
   drag-out файла (удержание), отменить/убрать.
5. VPN-плашка; выбор папки (+создание K DWNLD); очистка завершённых.
6. Брендинг: логотип kvartal (SVG из скилла webcore), кнопка Boosty.
7. Проверка экранов против сборки (pixel-compare) по мере готовности блоков.
