Заказчик прогнал приложение и показал два скриншота (макет vs живое). Что
вскрылось и починено:

  yt-dlp доходила до человека как безликое «Загрузка не удалась». Теперь
  honest-текст («Запись защищена от скачивания» для DRM и т.д.). Тест добавлен.

  p.link (= сырой текст), а надо по resolved. Теперь SoundCloud-результат
  сразу включает МУЗЫКУ и прячет ВИДЕО.
- [Ссылка] (пункт 5) для поиска скрывалась: src брался из p.link (не http).
  Теперь первый http из resolved/link/текста.
- Обложки поисковых результатов: у flat-playlist -J поле thumbnail часто
  пустое — добираем thumbnails[]/artwork_url (SoundCloud → t500x500).
- Корзина у упавших строк (убрать), крестик у ожидающих; повторный СКАЧАТЬ
  не дублирует ссылку, уже стоящую в очереди/работе; в строке очереди
  показываем название из разбора вместо сырого URL.
- Грабли: AX set_value во Flutter не триггерит onChanged (только клавиатура);
  контрольный сценарий проверки — «inmywhitee» (DRM-трек) и Flickermood (ок).
