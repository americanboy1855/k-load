# PRODUCT.md — K LOAD

## Что это

**K LOAD** — нативный загрузчик медиа для macOS (Flutter). Вставляешь ссылки или
название трека — получаешь файлы в своей папке. Вторая жизнь того же ядра —
VST3/AU-плагин для DAW (этап 3, после готовности приложения).

Уникальный механизм: **одно окно без режимов** — пачка ссылок с любых сервисов
и «наоборот» (по названию трека найти и скачать его) в одном потоке очереди;
закрытые каталоги (Spotify/Apple/Яндекс) читаются по открытому следу и
докачиваются через поиск, а вход из браузеров подбирается невидимо.

## Аудитория и сцена

Создатели и слушатели музыки (лейбл kvartal, свои релизы, ремиксы, референсы).
Работают за Mac, часто в DAW рядом; качают клипы для просмотра, треки для
работы, картинки для настроения. Часто под VPN — без него часть источников
молчит, поэтому в интерфейсе живёт мягкая подсказка про VPN.

## Задачи (v1)

- Источники: YouTube, YouTube Music, Instagram Reels, TikTok, Pinterest,
  ВК, Spotify, Apple Music, Яндекс Музыка, SoundCloud.
- Поиск по названию → видео или музыка на выбор пользователя.
- Только реально доступные качества; если неоднозначно — «Макс. качество».
- Пачка ссылок вперемешку; плейлист YouTube целиком.
- Очередь: превью (если сервис отдаёт), бейдж сервиса, живой прогресс,
  drag-out файла прямо из плашки.
- Папка назначения выбирается; внутри создаётся подпапка **K DWNLD**.
- Плашка VPN: «Для лучшей работы загрузчика - включите VPN».

## Бренд и обязательства

- Логотип **kvartal** обязателен в интерфейсе (SVG: `~/.zcode/skills/webcore/assets/brand/kvartal-logo.svg`).
- Кнопка доната: Boosty — https://boosty.to/kvartalrecords/donate
- Источник входа (cookies) пользователю не показывается — только результат.
- Русский язык интерфейса.

## Ограничения

- macOS первый (Windows позже); окно десктопное, не мобильное.
- Скачивание по одному заданию, фон, без параллельных потоков.
- Никакого старого мира CRT-телевизора — визуальный мир новый.

## Неизвестное

- Точный визуальный мир — решается роллом направлений (этот выбор за заказчиком).
- Подпись/нотаризация — нужен Apple Developer ID (спросить на этапе 4).
