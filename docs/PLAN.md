# K LOAD — план разработки

Нативный загрузчик медиа. Этап 1 (kdcore) — готов. Этап 2 (Flutter) — каркас
готов, интерфейс собирается блоками по референсам заказчика.
Полный контекст: `docs/HANDOFF-K-LOAD.md` (дубликат /tmp/HANDOFF-K-LOAD.md).

## Зафиксировано
- Имя: **K LOAD**. Папка загрузок: **K DWNLD** внутри выбранной пользователем папки.
- macOS первым; Windows позже. Единое C++ ядро без JUCE (`libkdcore` + C-API):
  Flutter через FFI, будущий VST — напрямую.
- Логотип kvartal (`~/.zcode/skills/webcore/assets/brand/kvartal-logo.svg`)
  + кнопка Boosty (boosty.to/kvartalrecords/donate) — войдут в интерфейс.

## Дизайн (изменено 07.09.2026)
Два раунда готовых визуальных миров (8 мокапов в `.impeccable/mocks/decision/`)
заказчик не выбрал: **дизайн собирает сам** — по своим стилям-референсам, блок
за блоком, начиная со структуры и меню. Роль агента: техническая сборка блоков
по референсам. Раунд-мокапы остаются архивом-вдохновением, обязательной силы не имеют.

## Этапы
1. ✅ `kdcore/` — чистый C++17, C-API kd_*, universal dylib, 52 контрактных
   теста (чистые + живые источники) зелёные. Git-история начата заново.
2. 🔄 `app/` — Flutter macOS: FFI-мост готов (`lib/kd/kd_bindings.dart`),
   технический каркас работает (движок грузится, инструменты находятся,
   события идут на Dart-порт). Дальше — блоки интерфейса по референсам:
   структура/меню → экран ввода → карточка → очередь → drag-out → брендинг.
3. (после готовности приложения) `plugin/` — JUCE 9 VST3/AU, общий кэш
   инструментов, auval/pluginval.
4. Подпись/нотаризация (нужен Apple Developer ID — спросить), .pkg, CI.

## Технические заметки
- Дев-сборка приложения: `app/scripts/dev-build.sh` (проект на iCloud-Desktop —
  провайдер портит подпись, поэтому бандл подписывается вне синхронизируемой
  зоны: «~/Library/Application Support/K LOAD dev/kload.app»).
- Инструменты: `core/tools` (докачка `core/fetch-tools.sh`; ffmpeg/ffprobe —
  только статические сборки evermeet, с внешними libs/ ядро не поднимет).
- Служба копий: движок пишет `~/Library/Application Support/K LOAD/engine.log`.
- Список блоков интерфейса для сборки — в конце сессии согласован с заказчиком
  (см. docs/HANDOFF-K-LOAD.md, раздел «Блоки интерфейса»).
